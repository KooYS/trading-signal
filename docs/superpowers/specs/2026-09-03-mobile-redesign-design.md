# 모바일 우선 화면 정리 — 설계 (2026-09-03)

## 왜

390px 폰에서 잰 결과: 첫 종목까지 ~1,500px(두 화면), 카드 하나 576px,
카드당 `?` 9개(114장이면 1,000개 넘는 터치 타깃), 필터바 3줄.
페이지의 일은 "오늘 뭘 살까 훑기" 하나인데 검증 통계·설명문·상세가 그 앞을 막고 있었다.

## 결정 (사용자 승인)

| 항목 | 결정 |
|---|---|
| 대시보드 6칸 | **한 줄 스트립**으로: 오늘 매수 · 오늘 매도 · 승률 · IR 공시. 기대값·시장대비는 사전으로 |
| 목록 | **압축 행** (이름·현재가·신호가 괴리·과열도·검증 배지·지지/저항) + 탭 → 상세 시트 |
| `?` 툴팁 | 전부 제거. **같은 페이지 안 `<dialog>` 사전**에 모은다. 헤더 ⓘ 와 상세의 라벨 탭으로 연다 |
| 검색 확대 | 모바일에서 input 16px (iOS 줌 조건 회피) |
| 삭제 | lede 설명문(→ 사전 '탭' 절), 부제, "개인 모니터링", `전체` 탭, 긴 푸터(→ 사전 '출처와 한계') |

## 구조

```
header   AI 매매 신호기 · [09-03 기준 · 방금 갱신] · ⓘ
strip    매수 114 · 매도 56 · 승률 65.7% · IR 3
bar      [검색] + 탭(오늘 매수 / 진행중 / 오늘 매도 / 청산 / ★)   ← sticky
caption  114건 · 과열도 낮은 순 · 수급 09-02 기준
list     행 … (데스크톱은 400px 열로 자동 채움, 모바일 1열)
dialog   사전: 이 신호기(3수치) → 탭 → 검증됨 → 참고용 → 무효 → 출처와 한계
```

행에 남기는 배지: 검증된 것(IR·과열/눌림) + 사용자가 명시적으로 원한 근거(PBR<1·적자·기관만 매도·진입 늦음).
공시·연속 순매수·거래량·동시매도는 상세로.

상세 시트: 데스크톱은 기존 3열 모달 그대로, 680px 이하에서 바텀시트(전폭, 92vh, 위 모서리 둥글게).
상세에 지지·저항 줄 추가(행에서 보이는 건 상세에도 있어야 한다).

## 검증

- 390px 에모듈레이션 스크린샷: 첫 행이 첫 화면 안에, 행 높이 ≤ 130px, 잘림 0
- 검색 input computed font-size ≥ 16px (모바일)
- 사전: ⓘ → 열림, 상세 라벨 탭 → 해당 항목으로 스크롤, Esc 닫힘
- 데스크톱 1340px 스크린샷: 열 자동 채움, 표 탭 정상
- 콘솔 에러 0, `node --check` 통과
